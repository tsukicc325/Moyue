## 2. 核心技术：100MB TXT 怎么读

**反面教材**：把整个文件读成 `String`。100MB GBK ≈ 5000 万汉字，转 UTF-16 就 100MB+ 堆内存，必 OOM。
**本方案**：全程分块流式，任意时刻内存中正文不超过几十 KB。

### 2.1 导入
- SAF `ACTION_OPEN_DOCUMENT`（单文件）+ `ACTION_OPEN_DOCUMENT_TREE`（扫文件夹），零存储权限
- 自动识别 ZIP 内的 txt
- 默认复制进 `files/books/<id>`：可 `FileChannel` 随机访问 + mmap，翻页最快、不怕原文件被删
- 可选「引用原文件」模式：`takePersistableUriPermission` 保住访问权，需处理失效 URI 与云盘流式读取

### 2.2 编码探测（中文 txt 最大的坑）
BOM（UTF-8/16LE/16BE/32）→ 严格 UTF-8 校验 → `juniversalchardet`（**已缓存，无需下载**）→ 兜底 GB18030（GBK/GB2312 超集）。
另提供**手动指定编码**，探测失败的文件也能救。

### 2.3 章节索引（关键设计）
- 按**字节流**分块扫描（1–4MB/块），`CharsetDecoder` 增量解码，正确处理多字节字符跨块
- **字节级定位技巧**：`0x0A`/`0x0D` 在 UTF-8 续字节（0x80–0xBF）与 GBK 尾字节（0x40–0xFE 除 0x7F）中都不出现 ⇒ 按字节找换行**精确**，章节字节偏移零成本获得，无需回写重编码算偏移
  （UTF-16 走 2 字节单元单独分支）
- 章节正则：`第X章/节/回/卷/篇/集/部`、`Chapter N`、`楔子/序章/序幕/前言/尾声/番外/终章/大结局`；支持自定义正则；排除「第X章」式日期误报
- **兜底**：无可识别章节或全书仅几章 → 按约 2 万字节在换行处切「虚拟分章」，保证超大单章也能分页
- **增量产出**：边扫边入库，扫到第 1 章即可开读；后台协程 + 通知栏进度 + 可取消
- 索引落 Room（`books/chapters/bookmarks/annotations/progress/sessions`），**二次打开毫秒级**；仅当 size+mtime 变化才重扫

### 2.4 分页与渲染
- 只读当前章节（或 2 万字块）字节窗口 → 解码 → `StaticLayout` 按当前字号/字体/行距/字距/缩进/对齐算页边界 → 自绘 `Canvas`
- 前后页预渲染，章节页表 LRU 缓存
- 字号/字体/行距/边距/旋转/分屏变化 → 防抖重新分页
- 翻页性能与文件大小**完全解耦**

### 2.5 性能目标（会在 PC 上用 JVM 基准真跑，出报告）

| 指标 | 目标 |
|---|---|
| 100MB GBK 建索引 | PC ≤ 5s，中端机 ≤ 20s |
| 索引峰值堆内存增量 | ≤ 32MB |
| 翻页耗时 | ≤ 16ms |
| 已索引书籍二次打开 | ≤ 300ms |
| 基准样本 | 100MB GBK / UTF-8 / 单行无换行 / 含误报章节，各一份 |

## 3. 界面与功能

### 书架
网格/列表切换、自动生成封面（书名首字 + 书名哈希渐变色 + 进度角标）、长按菜单（改名/换封面/分组/删除）、搜索、排序（最近阅读/添加时间/书名/进度）、分组标签页、继续阅读悬浮按钮、导入 FAB

### 阅读页
沉浸全屏、点击分区（左翻/中间菜单/右翻，可自定义）、音量键翻页、翻页动画（覆盖/仿真/滑动/无动画/上下滚动）、上下菜单、页脚（时间/电量/页码/百分比）、屏幕常亮

### 排版（设置面板）
字号、字体（系统 + **导入 ttf/otf**）、行距、段距、字距、首行缩进、两端对齐、加粗、上下左右边距

### 主题
白/纸黄/护眼绿/夜间/纯黑、**自定义背景图 + 透明度**、**亮度独立调节**（不跟随系统，含手势下滑调亮度）

### 目录与进度
章节列表 + 当前章高亮 + 章节搜索、章节内与全书双进度条、拖动跳转、剩余阅读时间

### 增强功能（一期）
- **全文搜索**：流式扫描带进度，结果列表（章节 + 上下文），点击跳转并高亮
- **自动翻页 / 自动滚屏**：速度可调
- **阅读统计**：时长/天数/速度（字/分），自绘柱状图
- 书签、划线选中（复制/书签/搜索/分享）、笔记列表

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| Maven Central 慢导致依赖卡住 | 阿里云镜像优先 + `GRADLE_USER_HOME` 复用已有缓存；Compose 探针已先行验证 |
| 原生 txt 无换行（单行 100MB） | 字节窗口扫描 + 虚拟分章，不依赖行结构 |
| 章节正则误报/漏报 | 保守正则 + 自定义正则 + 虚拟分章兜底 + 手动改章节规则 |
| 云盘 content:// 无法随机访问 | 默认复制到私有目录；引用模式作为可选并做失效检测 |
| 超大单章内存 | 强制 2 万字块切分，块内分页 |
| 字体/主题变化导致分页漂移 | 统一由分页器单一入口重算 + 防抖 |
